# FSH Store Listing Draft

## Short description
Connect, share, create Pages, and discover communities on FSH.

## Full description
FSH is a social network for connecting with people, sharing posts and photos, discovering communities, and creating public Pages for businesses, creators, communities, and brands.

### Features
- Create an FSH account and sign in securely
- Build your profile
- Publish posts and photos
- React, comment, and share
- Create and manage public Pages
- Discover people, groups, events, Marketplace, Watch, and more
- Search the FSH community
- Mobile-first experience
